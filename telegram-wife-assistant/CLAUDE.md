# CLAUDE.md — دليل للـ AI agents اللي بيشتغلوا على المشروع ده

## نظرة عامة
بوت تيليجرام **مساعد شخصي لمستخدم واحد**. بيقترح للمالك رسايل دافئة باللهجة
المصرية لزوجته، **ويبعتها للمالك فقط**. دورة تحسين مغلقة بتقرّب الاقتراحات من
أسلوب المالك عبر **تعلّم بالسياق** (few-shot)، مش تدريب نموذج.

## قواعد لا يجوز كسرها
1. **الإرسال للمالك فقط** (`config.chatId`). ممنوع أي إرسال لأي طرف تاني، ممنوع
   أي تكامل مع واتساب أو الزوجة. لو عدّلت كود الإرسال، حافظ على ده.
2. **مفيش إرسال تلقائي خارجي.** البوت بيقترح للمالك، والمالك بيبعت بإيده.
3. **الأسرار في `.env` بس** (`TELEGRAM_BOT_TOKEN`, `GROQ_API_KEY`). ممنوع أي سر في الكود.
4. **التعلّم = in-context** (أمثلة في الموجّه). ممنوع تسمّيه "تدريب" أو تضيف fine-tuning.
5. **مرساة الصوت** في `buildSystemPrompt()` لازم تفضل ثابتة عشان الأسلوب ما ينحرفش.

## الملفات
- `index.js` — تشغيل + جدولة node-cron (Asia/Dubai) + فحص المناسبة + الدورة.
- `bot.js` — تيليجرام: إرسال، أزرار inline، التقاط الردود، أوامر `/start /stats /reset`.
- `generateSuggestion.js` — توليد اقتراحين + ترجيح المواضيع + few-shot + مرساة الصوت.
- `occasions.js` — مناسبة النهاردة من config (fixed MM-DD / manual YYYY-MM-DD).
- `llm.js` — تجريد Groq (متوافق OpenAI). المزوّد معزول هنا بس.
- `store.js` — JSON: feedback / styleExamples (≤30) / themeWeights / lastSentPerSlot.
- `review.js` — التقرير: نسبة القبول، أعلى المواضيع، الخانة المتجاهَلة.
- `util.js` — أدوات مشتركة (تاريخ النهاردة/todayParts) — مصدر واحد يمنع التكرار.
- `config.js` — كل الإعدادات (مفيش أسرار).
- `test.js` — يطبع اقتراحات بدون إرسال (mock لو مفيش مفتاح).

## تجنّب التكرار (DRY)
- حساب التاريخ في `util.js` بس؛ `store.js` و`occasions.js` بيستوردوا منه.
- `bot.js`: معالج pick واحد بمصنع `handlePick(idx)`، و`recordFeedback()` موحّد.

## ثبات الحالة
`store.lastSentPerSlot[slot] = today` يمنع إرسال نفس الخانة مرتين في نفس اليوم
حتى مع إعادة التشغيل. أي تعديل على الجدولة لازم يحافظ على ده.

## التشغيل
```bash
npm install
npm test        # تجربة بدون إرسال
npm start       # تشغيل (احترم dryRun في config.js)
```

## أسلوب الكود
- CommonJS (`require`/`module.exports`).
- تعليقات بالعربي، أسماء واضحة، دوال صغيرة نقية حيثما أمكن.
- ما تضيفش dependencies غير الضرورية (telegraf, node-cron, dotenv بس؛ Groq عبر fetch).
