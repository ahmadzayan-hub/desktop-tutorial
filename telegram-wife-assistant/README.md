# مساعد تيليجرام الشخصي لاقتراح رسايل 💌

مساعد شخصي **ليا أنا فقط** على تيليجرام. في الصباح والمساء وفي المناسبات بيقترح
ليا رسالتين دافئتين باللهجة المصرية لزوجتي، **ويبعتهم ليا أنا**. أنا اللي بختار
وبعدّل وببعت بإيدي من واتساب. مع كل استخدام، الاقتراحات بتتحسّن وتقرب من أسلوبي.

> 🔒 **حدود صارمة:** البوت بيكلّمني أنا بس. مفيش أي اتصال بزوجتي ولا واتساب،
> ومفيش إرسال تلقائي لأي حد. هو مساعد ليا، مش وسيط.

---

## إزاي بيتعلّم؟ (مهم)

ده **تعلّم بالسياق** (in-context learning): البوت بياخد آخر رسايل انت اخترتها أو
عدّلتها ويحطها كأمثلة (few-shot) في الموجّه، فالموديل **يقلّد صوتك**. إحنا **مش**
بندرّب نموذج ولا بنعدّل أوزانه — مفيش أي تدريب ولا تكلفة. كل التعلّم في ملف JSON محلي.

في **مرساة صوت** ثابتة (برومبت نظام ثابت) بتحافظ على نبرة أساسية عشان الأسلوب
ما ينحرفش مع تعديل أو اتنين. ولو حسّيت إنه انحرف: أمر `/reset` يصفّر التعلّم.

## التقنيات (كلها مجانية)

- **Node.js** (CommonJS)
- **telegraf** — بوت تيليجرام (Bot API الرسمي، مجاني)
- **node-cron** — الجدولة بتوقيت `Asia/Dubai`
- **Groq** — عقل الـ AI (طبقة مجانية)، معزول في `llm.js`
- **dotenv** — الأسرار
- تخزين محلي: ملف **JSON** (`data/store.json`)

## التثبيت

أسهل طريقة — سكربت التجهيز (بيعمل كل حاجة ويسألك عن التوكن والمفتاح):

```bash
cd telegram-wife-assistant
chmod +x setup.sh && ./setup.sh
```

أو يدوياً:

```bash
cd telegram-wife-assistant
npm install
cp .env.example .env     # واملا التوكن ومفتاح Groq
```

## 1) إعداد بوت تيليجرام

1. افتح **@BotFather** على تيليجرام → `/newbot` → اختار اسم ويوزرنيم.
2. هياخد **توكن**. حطه في `.env`:
   ```
   TELEGRAM_BOT_TOKEN=123456789:AA....
   ```

## 2) جلب الـ chat_id بتاعك

1. شغّل البوت: `npm start`
2. ابعت `/start` للبوت من حسابك.
3. البوت هيطبع الـ `chat_id` في الكونسول (وكمان هيبعتهولك).
   - بديل: استخدم **@userinfobot**.
4. حطه في `config.js` (`chatId`) أو في `.env` كـ `MY_CHAT_ID`، وأعد التشغيل.

## 3) مفتاح Groq المجاني

روح [console.groq.com/keys](https://console.groq.com/keys)، خد مفتاح، وحطه في `.env`:
```
GROQ_API_KEY=gsk_....
```

## التجربة بدون إرسال

```bash
npm test       # node test.js — يطبع اقتراح صباحي/مسائي/مناسبة، مفيش إرسال
```
لو لسه مفيش مفتاح Groq، هيشتغل بمولّد وهمي عشان تشوف الشكل.

## التشغيل في وضع التطوير (dryRun)

في `config.js` خلّي `dryRun: true`. شغّل:
```bash
npm start
```
هيطبع الاقتراحات في الكونسول بدل ما يبعتها. جرّب `/start` و `/stats` و `/reset`.
لما تطمّن، خلّي `dryRun: false` عشان يبعت لك فعلاً على تيليجرام.

## الدورة المغلقة

**توليد ← تسليم ← التقاط ← تعلّم ← مراجعة**

- **توليد:** اقتراحين مختلفين، مواضيع متنوّعة (امتنان، اشتياق، تقدير، دعم، دعاء...)
  مع تجنّب مواضيع آخر كام يوم وترجيح اللي بتختاره أكتر.
- **تسليم:** رسالة بأزرار: `1️⃣ اختار الأول` · `2️⃣ اختار الثاني` · `🔄 جديد` · `🙈 تجاهل`.
  وكمان تقدر ترد بنسختك المعدّلة كنص حر.
- **التقاط:** ضغط الأزرار والرد النصي بيتسجّلوا في `data/store.json`.
- **تعلّم:** اختيارك/تعديلك يدخل ملف الأسلوب (آخر 30)، والمواضيع يتعدّل وزنها.
- **مراجعة:** تقرير أسبوعي تلقائي + أمر `/stats` وقت ما تطلبه.

## الأوامر

| الأمر | الوظيفة |
| --- | --- |
| `/start` | ترحيب + يطبع الـ chat_id |
| `/suggest` | اقتراح فوري (من غير ما تستنى الميعاد) |
| `/occasion` | اقتراح مناسبة — يستخدم مناسبة النهاردة، أو اكتب `/occasion عيد جوازنا` |
| `/morning` · `/evening` | اقتراح صباحي/مسائي فوري |
| `/stats` | ملخّص: نسبة القبول، أعلى المواضيع، أمثلة الأسلوب |
| `/reset` | تصفير التعلّم لو الأسلوب انحرف |

**نسخ أسهل:** تحت كل اقتراح فيه زراير `📋 انسخ` بتنسخ النص للـ clipboard بضغطة
واحدة. ولما تختار اقتراح، البوت بيبعتهولك في رسالة لوحدها تسهّل النسخ/الـ forward.

## المناسبات

في `config.js` تحت `occasions`:
- **عيد الجواز / عيد ميلاد الزوجة:** تاريخ ثابت `MM-DD`.
- **الأعياد الإسلامية:** `manual` — انت بتدخّل `YYYY-MM-DD` المؤكد كل سنة من تقويم
  موثوق. مفيش حساب أعمى. وبما إن الاقتراح بيوصل لك انت بس، أي خطأ ما بيوصلش لزوجتك.

قبل اقتراح الصباح كل يوم، البوت بيفحص لو النهاردة مناسبة ويقترح رسالة مخصّصة لها.

## التشغيل الدائم بـ pm2 (مجاني)

على جهاز بتملكه (أو Oracle Cloud Always Free):

```bash
npm install -g pm2
pm2 start ecosystem.config.js   # إعداد جاهز (اسم + إعادة تشغيل تلقائي + لوجات)
pm2 save                        # يحفظ القائمة
pm2 startup                     # يخلّيه يشتغل مع إقلاع الجهاز (نفّذ السطر اللي هيطلعلك)
pm2 logs wife-assistant         # يتابع اللوجات
pm2 restart wife-assistant
pm2 stop wife-assistant
```

> ⚠️ لازم الجهاز يفضل **شغّال** عشان الجدولة وأزرار التغذية الراجعة تشتغل.
> البوت خفيف وبيستخدم long polling، فيشتغل على أي جهاز بسيط.
