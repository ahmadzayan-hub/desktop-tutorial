# وصال لويندوز (Wisal Desktop)

نسخة سطح المكتب من وصال — مبنية بـ **Electron**، بواجهة مظبوطة للّابتوب وويندوز
(شريط جانبي، شاشة عريضة، ثيم فاتح/غامق، عربي RTL). خفيفة ومناسبة لهاردوير متوسط.

## المميزات
- اقتراح رسالتين دافئتين حسب الشخص والعلاقة واللهجة والنبرة.
- نيّة الرسالة (اعتذار/تهنئة/مواساة...) + خانة سياق سريع.
- تحرير تكراري (أطول/أقصر/أرومانسي/أبسط) + تعلّم من اختياراتك.
- مناسبات جايّة + أفكار عملية للمناسبة.
- إرسال عبر واتساب ويب بضغطة (بيفتح المتصفح والرسالة جاهزة، وانت تبعت بإيدك).
- سجل + مفضّلة + بحث. كله محلي على جهازك، والمزوّد الوحيد Groq وقت التوليد.

## التنزيل
أحدث نسخة جاهزة على GitHub Releases تحت تاج `windows-latest`:
- `Wisal-Setup.exe` — تثبيت عادي (بدون صلاحيات أدمن).
- `Wisal-Portable.exe` — نسخة محمولة من غير تثبيت.

> أول تشغيل ممكن Windows SmartScreen يحذّر لأن البرنامج مش موقّع تجارياً —
> اضغط **More info** ثم **Run anyway**. (التوقيع التجاري خطوة لاحقة اختيارية.)

## التشغيل للتطوير
```bash
cd wisal-desktop
npm install
npm start
```

## البناء محلياً (على ويندوز)
```bash
npm run dist
# الناتج في wisal-desktop/dist/
```

## المتطلبات
Windows 10 أو أحدث (WebView من Electron مدمج). محتاج مفتاح Groq مجاني من
console.groq.com/keys تحطه أول مرة في التطبيق.
