# 🔌 وصال — ربط القنوات (واتساب متعدد / إنستجرام / ماسنجر / لينكدإن)

توضيح صريح لما هو ممكن فعلاً، ما هو مش ممكن (وليه)، واللي اتنفّذ في الإصدار ده،
والمسار الصح للتكامل الحقيقي للأعمال. الهدف قرارات مبنية على الواقع مش وعود.

---

## 1) اللي اتنفّذ فعلاً (على الجهاز، آمن ومشروع)

### أ) حسابات مُرسِل متعددة (واتساب) — `SenderAccount`
- تقدر تعرّف حساباتك (مثلاً: **الإمارات / مصر / الأعمال**) — كل حساب: اسم + كود دولة
  افتراضي + توقيع + **القناة** (واتساب عادي / واتساب Business).
- الاختيار بيظبط: التطبيق اللي بيتفتح (عادي/Business)، كود الأرقام الناقصة، والتوقيع
  اللي بيتزاد آخر كل رسالة.
- الإرسال زيّ ما هو: بيفتح شات العميل والرسالة جاهزة، **وانت تدوس Send** (مفيش أتمتة).

### ب) جسر إنستجرام / ماسنجر / لينكدإن — `SocialShare`
- بتجهّز الرسالة المخصّصة جوّه التطبيق (بلغة الشخص ونبرته)، وبضغطة **بننسخها ونفتح**
  التطبيق/البروفايل، وانت **تلصقها وتبعت**.

### ج) اللغة حسب لغة المستقبل — عربي/إنجليزي (تلقائي)
- لكل شخص: تلقائي (نكشف من اسمه/رسايله) أو عربي أو إنجليزي. كل التوليد بيحترمها.

## 2) اللي **مش** ممكن على الجهاز — وليه (مهم)

| الطلب | ممكن؟ | السبب |
|-------|:----:|-------|
| «ربط/تسجيل دخول» حسابات واتساب الشخصية داخل التطبيق | ❌ | واتساب **مفيهاش API عام للأرقام الشخصية**. مفيش تطبيق يقدر يسجّل دخول أو يبعت من رقمك الشخصي تلقائيًا. |
| التبديل برمجيًا بين رقمين واتساب شخصيين | ❌ | الرقمين بيبقوا في **نفس التطبيق** (أو تطبيق مزدوج على الجهاز). الاختيار ده قرار جهاز/شريحة، مش حاجة التطبيق يتحكّم فيها. |
| إرسال DM إنستجرام/ماسنجر/لينكدإن من التطبيق | ❌ | المنصّات دي مابتسمحش لتطبيق تالت يبعت رسايل، ولينكاتها **مابتقبلش نص جاهز** (عكس `wa.me`). |
| بلاست جماعي تلقائي (واتساب) | ❌ عمدًا | بيعرّض رقمك **للحظر**. الوضع الآمن الوحيد: رسالة مخصّصة + ضغطة لكل شخص عنده محادثة معاك. |

> الخلاصة: أي «تكامل» بيّدّعي إرسال تلقائي من حساباتك الشخصية على المنصّات دي هيكون
> **مخالف لشروطها** ومعرّض حساباتك للحظر. إحنا اخترنا الطريق المشروع.

## 3) المسار الحقيقي للأعمال (Backend — خطوة جاية)

لو عايز **إرسال آلي مشروع للعملاء**، الطريق الرسمي الوحيد هو **WhatsApp Business
Cloud API** من Meta — ومحتاج:

1. **حساب Meta Business** موثّق + رقم مخصّص للـ API (مش رقمك الشخصي).
2. **قوالب رسائل معتمدة** من Meta (Template Messages) للرسائل خارج نافذة الـ24 ساعة.
3. **سيرفر** يحفظ الـ Access Token بأمان وينادي الـ API (ماينفعش من التطبيق مباشرة).
4. الرد الحر مسموح بس **جوّه 24 ساعة** من آخر رسالة بعتها العميل ليك.

- **انستجرام/ماسنجر:** عبر **Meta Messenger Platform / Instagram Messaging API** —
  بردو سيرفر + توكنز + مراجعة تطبيق، وبس لعملاء **بدأوا** محادثة مع صفحتك/حسابك.
- **لينكدإن:** الـ Messaging API شبه مقفول (شركاء فقط) — عمليًا: جهّز + انسخ + افتح.

ده مشروع Backend منفصل محتاج **حساباتك ومفاتيحك** — نقدر نعمله كمرحلة تانية بسيرفر
(مثلاً Supabase/Vercel Functions) لما تجهّز حساب Meta Business.

---

## 4) نصايح تشغيلية

1. **رقمين شخصيين؟** استخدم «تطبيق مزدوج» في إعدادات جهازك (Dual Apps / Parallel
   Space) أو شريحتين — بعدها اختار الحساب في وصال عشان الكود/التوقيع/التطبيق يظبطوا.
2. **الأعمال؟** فعّل «وضع الأعمال» أو اختار حساب قناته Business — بيفتح واتساب Business
   بنبرة مهنية. راجع خطة الـ Cloud API فوق لو محتاج أتمتة فعلية.
3. **الأجانب؟** حدّد لغة الشخص «إنجليزي» (أو سيبها تلقائي) — الرسالة تطلع إنجليزي طبيعي.
4. **متعملش سبام:** حتى بالضغطة اليدوية، بلاش تبعت نفس النص لعشرات بسرعة — الرسايل
   المخصّصة بتقلّل خطر الحظر أصلاً.
