# 🔧 MCP / Agentic-Tools — الأدوات

الأدوات اللي الوكيل بينفّذ بيها في العالم الحقيقي. كلها **بموافقة/بضغطة المستخدم**.

| الأداة | الوظيفة | المنصّات | خصوصية |
| --- | --- | --- | --- |
| **WhatsApp** | يفتح الشات والرسالة جاهزة (`wa.me`) | أندرويد + ديسكتوب (متصفح) | مفيش إرسال تلقائي |
| **Contacts** | استيراد أعياد الميلاد + بثّ مخصّص | أندرويد | قراءة محلية بإذن، مفيش رفع |
| **Calendar** | اقتراح مناسبة من الأجندة | أندرويد | قراءة محلية بإذن |
| **Clipboard** | نسخ الرسالة | أندرويد + ديسكتوب | محلي |
| **Share** | مشاركة عامة لأي تطبيق | أندرويد | يختار المستخدم الوجهة |
| **Notifications** | تذكيرات المواعيد و"بقالك فترة" | أندرويد | محلي |

> ملاحظة: "MCP" هنا مفهوم تنظيمي (أدوات الوكيل)، مش بروتوكول MCP الحرفي — التطبيقات
> محلية بدون سيرفر. أي تكامل حقيقي مستقبلي (مثلاً أسعار من متجر) هيتوثّق هنا كأداة جديدة
> مع مزوّدها ومتطلباتها.

## إضافة أداة
عرّف: الاسم، الوظيفة، المنصّة، الإذن المطلوب، والخصوصية — وحدّث تبويب Tools في الديسكتوب.
