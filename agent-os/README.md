# Agent OS — خريطة وصال كنظام agentic (Claude OS)

ده الطبقة التنظيمية اللي بتوصف منتج **وصال (Wisal)** كأنه **نظام تشغيل agentic**:
عوض ما نبصّ للمشروع كتطبيق، بنبصّله كـ **عقل + أدوات + ذاكرة + مهارات + وكلاء + موديل**.
الغرض: تنظيم التطوير، ووضوح "مين بيعمل إيه"، وأساس نبني عليه أي توسّع جاي.

> النطاق: عائلة منتجات وصال (أندرويد + ديسكتوب + موقع الهبوط). مشروع `lahza` في
> جذر الريبو منفصل تماماً ومش جزء من الـ Agent OS ده.

## الأعمدة الستة

| العمود | يعني إيه في وصال | فين في الكود |
| --- | --- | --- |
| 🤖 **Agents** | الوكلاء اللي بينفّذوا مهام (المؤلِّف، المذكِّر، وكيل المناسبات، البثّ) | `agent-os/agents/` |
| 🧩 **Skills** | المهارات اللي الوكيل بيطبّقها (نيّات الرسالة، التحرير التكراري، أفكار الهدايا) | `agent-os/skills/` |
| 🔧 **MCP / Agentic-Tools** | الأدوات اللي الوكيل بينفّذ بيها (واتساب، جهات الاتصال، التقويم، الحافظة، المشاركة) | `agent-os/mcp/` |
| 🗄️ **Memory** | ذاكرة المشروع: تقدّم العمل + سجل الجلسات + التعلّم | `agent-os/memory/` |
| 🧠 **Brain (Second Brain)** | العقل الثاني: معرفة كل شخص (الأسماء، الملاحظات، المناسبات، أمثلة الأسلوب) | `agent-os/brain/` |
| ✨ **LLM** | المحرّك اللغوي (Groq + الموديلات + مراسي الصوت) | `agent-os/llm/` |

## إزاي بيشتغلوا مع بعض
```
        نيّة + سياق (Skills)
                 │
   Brain (معرفة الشخص) ─► Agent (المؤلِّف) ─► LLM (Groq) ─► اقتراحين
                 │                                   │
             Memory (تعلّم أسلوبك)  ◄── اختيارك ──────┘
                 │
          MCP Tools (واتساب) ─► انت تبعت بإيدك
```

## المبادئ الثابتة
- **الوكيل بيتكلم معاك انت بس.** مفيش إرسال تلقائي لأي حد؛ الضغطة الأخيرة بإيدك.
- **الذاكرة والعقل على جهازك.** المزوّد الوحيد الخارجي هو الـ LLM وقت التوليد.
- **إنسان في الحلقة (Human-in-the-loop)** في كل خطوة حسّاسة.
