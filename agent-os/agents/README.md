# 🤖 Agents — الوكلاء

كل وكيل مسؤول عن مهمة واحدة واضحة، وبيستخدم Skills + Tools + Brain + LLM.

| الوكيل | المهمة | المدخلات | المخرجات | ملاحظات |
| --- | --- | --- | --- | --- |
| **Composer** (المؤلِّف) | يقترح رسالتين دافئتين للشخص المختار | الشخص، النيّة، السياق، اللهجة | اقتراحين + موضوع لكل واحد | القلب الأساسي. أندرويد: `SuggestionEngine` · ديسكتوب: `lib/core.generate` |
| **Refiner** (المُحرِّر) | يعيد صياغة اقتراح بستايل مطلوب | نص + ستايل (أطول/أقصر/أرومانسي/أبسط) | نص معدّل | تحرير تكراري |
| **Reminder** (المذكِّر) | ينبّه "بقالك فترة ما كلّمت فلان" و"ابعت بكرة" | آخر تواصل + إعدادات | إشعار (بدون إرسال) | أندرويد: `ReminderWorker` / `SendReminder` |
| **Occasion** (وكيل المناسبات) | يكتشف مناسبة قريّبة ويجهّز رسالة/أفكار | مناسبات الأشخاص + التقويم | تنبيه مبكّر + أفكار عملية | تنبيه قبل المناسبة بأيام |
| **Broadcast** (البثّ) | يجهّز رسالة مخصّصة باسم كل جهة اتصال | قالب + جهات الاتصال | قائمة إرسال بضغطة لكل شخص | أندرويد فقط حالياً؛ مفيش بلاست تلقائي |

## قواعد الوكلاء
- كل وكيل **لا يبعت تلقائياً**؛ بيجهّز والقرار النهائي للمستخدم.
- عند غياب النت/المفتاح، وكيل Composer بيرجع لبنك رسائل جاهز (Fallback) بدل ما يقف.
