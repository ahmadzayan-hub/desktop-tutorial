# 🧩 Skills — المهارات

مهارات الوكيل بيطبّقها على المهمة. المهارة = توجيه للنبرة/الشكل بدون تغيير الأدوات.

## نيّات الرسالة (Intent Skills)
اعتذار · تهنئة · مواساة · شكر · اشتياق · طمأنة · دعم · دعاء.
كل نيّة عندها `hint` بيوجّه الـ LLM للموقف الحقيقي.
(أندرويد: `Intents.kt` · ديسكتوب: `INTENTS` في `lib/core.js`)

## مهارات التحرير (Refine Skills)
أطول · أقصر · أرومانسي أكتر · أبسط. بتعيد صياغة اقتراح موجود مع الحفاظ على المعنى.

## مهارات مساعدة
- **اكتشاف اللهجة والنبرة لكل شخص** (مصري/خليجي/شامي/فصحى + نبرة خاصة).
- **أفكار الهدايا/اللمسات** للمناسبة (أفكار + فئة سعرية تقريبية، بدون أسعار حقيقية).
- **التعلّم بالسياق (Few-shot)**: تلقيم آخر أمثلة أسلوبك للوكيل بدل تدريب موديل.

## إضافة مهارة جديدة
1. عرّف المهارة (id + label + hint).
2. وصّلها في بناء البرومبت (system/user).
3. اعرضها كـ Skill في واجهة الديسكتوب (تبويب Skills).
