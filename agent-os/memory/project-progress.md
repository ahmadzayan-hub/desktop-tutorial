# 🗄️ Memory — تقدّم المشروع (Project Progress)

سجل حيّ لأهم ما اتبنى في عائلة وصال. بيتحدّث مع كل مرحلة.

## المنتجات
- **بوت تيليجرام** (`telegram-wife-assistant/`) — أول تجسيد للفكرة: اقتراح رسائل +
  دورة تعلّم مغلقة (توليد → اختيار → تعلّم). Node/CommonJS.
- **تطبيق أندرويد** (`android-wife-assistant/`) — Kotlin + Jetpack Compose، المنتج الأساسي.
- **موقع الهبوط** (`wisal-web/`) — SEO/AIO + صفحة خصوصية + أزرار تنزيل أندرويد/ويندوز.
- **تطبيق ويندوز** (`wisal-desktop/`) — Electron، واجهة مظبوطة للّابتوب.
