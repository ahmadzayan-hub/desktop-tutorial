# ✨ LLM — المحرّك اللغوي

العقل اللغوي اللي بيحوّل المعرفة + المهارة لرسالة. مزوّد واحد معزول.

## المزوّد
- **Groq** (طبقة مجانية، OpenAI-compatible) عبر `chat/completions`.
- الموديلات:
  - `llama-3.3-70b-versatile` — الأفضل للعربي (افتراضي).
  - `llama-3.1-8b-instant` — أسرع.

## مراسي الصوت (Voice Anchors)
- برومبت نظام ثابت بيحدّد: العلاقة، النبرة، اللهجة، الطول، الإيموجي، الدُعابة.
- سقف على تأثير أمثلة الأسلوب عشان الصوت ما ينحرفش.
- درجات حرارة: توليد 0.8 · تحرير 0.7 · تحليل 0.3.

## الخصوصية
- بيتبعت **سياق الرسالة اللازم للتوليد بس** (علاقة/اسم/ملاحظات/مناسبة) — مفيش أرقام
  ولا جهات اتصال. المفتاح مشفّر على الجهاز (أندرويد Keystore).
- بدون نت/مفتاح → الوكيل بيرجع لبنك رسائل جاهز محلي.

## نقاط التوصيل في الكود
- أندرويد: `GroqClient.kt` (retry/backoff) · ديسكتوب: `groqComplete` في `lib/core.js`.
- أي تبديل مزوّد بيتعمل هنا فقط (معزول).
