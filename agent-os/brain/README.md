# 🧠 Brain — العقل الثاني (Second Brain)

معرفة الوكيل عن الأشخاص وأسلوبك. كلها **محلية على الجهاز**. ده اللي بيخلّي الرسائل
"ليهم هم بالذات ومنّك انت".

## نموذج المعرفة (لكل شخص)
| الحقل | يعني | استخدامه |
| --- | --- | --- |
| `name` | الاسم/الدلع | ينادي بيه في الرسالة |
| `relation` | العلاقة | يحدّد النبرة الافتراضية |
| `tone` | نبرة خاصة | تغلب على الافتراضي |
| `dialect` | اللهجة | مصري/خليجي/شامي/فصحى |
| `notes` | حاجات عنه (بيحب إيه، ذكريات) | تخصيص محسوس بدون سرد |
| `occasions` | مناسباته (MM-DD) | تنبيه + رسائل مخصّصة |
| `photoPath` | صورته (من المعرض) | أفاتار |
| `number` | واتساب | أداة الإرسال |

## ذاكرة الأسلوب (Style Memory)
- `styleExamples` لكل شخص (آخر 30): الرسائل اللي اخترتها/عدّلتها = صوتك.
- `themeWeights`: ترجيح المواضيع اللي بتميل لها.
- الوكيل بيلقّم دي للـ LLM (few-shot) عشان يقلّد روحك، **من غير تدريب موديل**.

## مصادر المعرفة (بموافقتك، بدون سحب)
- إدخال يدوي · تحليل معلومات بتلصقها (بايو/بوست) · استيراد من جهات الاتصال/التقويم.
- **مفيش سحب تلقائي من سوشيال ميديا لأي طرف** (تقني + قانوني + مبدأ التطبيق).
